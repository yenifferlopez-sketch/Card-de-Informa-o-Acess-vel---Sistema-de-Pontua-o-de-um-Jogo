# ♿ Acessibilidade na Escola

## Sobre o projeto
Este projeto é uma página web informativa desenvolvida com HTML5 e CSS3 para apresentar boas práticas de acessibilidade no ambiente escolar. A página organiza seis temas fundamentais em cards visuais simples, objetivos e responsivos, facilitando a leitura tanto no computador quanto no celular.

## Tecnologias
- HTML5
- CSS3
- GitHub
- GitHub Pages

## Práticas de acessibilidade
- **Texto fácil de compreender:** Frases curtas, diretas e divididas por tópicos.
- **Boa organização:** Uso de HTML semântico (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) e divisão em cards.
- **Contraste adequado:** Texto escuro (`#1E293B`) sobre fundo claro (`#FFFFFF` e `#F4F6F9`) e cabeçalho azul escuro com letras brancas.
- **Fonte legível:** Uso da fonte `Verdana` em tamanho `17px` com espaçamento entre linhas confortável (`1.6`).
- **Poucas cores e sem distrações:** Paleta neutra sem animações ou elementos piscantes.
- **Botão claro com foco visível:** Botão destacado e com contorno nítido ao navegar pelo teclado.
- **Imagem com atributo `alt`:** Descrição textual explicando o conteúdo visual da ilustração.

## Reflexão
**Qual foi a principal preocupação que você teve ao criar uma página acessível?**

A principal preocupação foi garantir que qualquer pessoa consiga ler e entender todas as informações sem cansaço visual ou confusão. Para isso, evitei o excesso de cores, animações e textos longos, organizando o conteúdo em blocos separados com títulos claros. Também priorizei o alto contraste entre o fundo e as letras, além de usar uma estrutura HTML semântica que funciona bem tanto para leitura visual quanto para leitores de tela. Dessa forma, a página se torna previsível, confortável e inclusiva em qualquer dispositivo.
